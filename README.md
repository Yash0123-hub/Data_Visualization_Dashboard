# 📊 Data Visualization Dashboard Using Python

## Project Overview
This project develops an interactive Data Visualization Dashboard using Python and Plotly. The dashboard helps users analyze business data through interactive charts and visualizations, making it easier to identify trends and support decision-making.

## Problem Statement
Organizations collect large amounts of data from different sources, but static reports make it difficult to understand trends and performance. An interactive dashboard provides a better way to explore and visualize data.

## Objectives
- Develop an interactive dashboard using Python.
- Visualize sales and profit data.
- Display information using multiple chart types.
- Provide interactive features for data analysis.
- Present meaningful business insights.

## Technologies Used

- Python
- Google Colab
- Pandas
- Plotly

## Features

- Interactive Bar Chart
- Interactive Line Chart
- Interactive Pie Chart
- Interactive Scatter Plot
- Dataset Summary Statistics
